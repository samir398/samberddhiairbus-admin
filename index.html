Create Coupon
Enter a discount % and the price auto-fills — or type an exact "Price / Seat" yourself to set it directly (it will override the %).
Leave the dates blank for a coupon that never expires. Set "Valid Until" to make it automatically stop working (and show as Expired here) after that date.
Leave "Max Uses" blank for unlimited uses. A "use" is counted as one non-cancelled booking made with that code — once the limit is hit, the coupon shows as Limit Reached here and customers will no longer be able to apply it on the booking site.
Active coupons appear instantly on the customer booking site (Choose Seats step). Customers enter the code to get the discounted price per seat.
